크림색 종이 위의 GT Super 마스트헤드

Medium은 "소프트웨어를 배우게 된 문예지"처럼 읽힌다. 로그아웃 홈페이지는 순백이 아니라 따뜻한 종이색 #F7F4ED 위에서 열리고, 단 하나의 세리프 헤드라인 "Human stories & ideas"가 GT Super로 최대 120px, 순흑 #000000, 자간 -0.055em으로 모든 말을 대신한다. SaaS 랜딩의 히어로가 아니라 신문의 제호(masthead)다.

정체성은 두 개의 타입 인격 사이의 긴장이다. 고대비 세리프 GT Super가 브랜드 보이스(워드마크 · 헤드라인)를, 클린 그로테스크 Söhne가 모든 기능 표면(내비 · 서브타이틀 · 버튼 · 푸터)을 맡는다. 제3의 목소리는 없다. 읽기 경험 자체는 Charter라는 또 다른 세리프로 돌아간다 — 세 폰트, 세 역할, 겹침 없음.

색은 배급제다. 브랜드는 단 하나의 잔디 그린 #1A8917이며 크롬 위에는 거의 나타나지 않는다. 손그림 일러스트, 인라인 링크, 기본 버튼의 한 가지 변형에만 산다. 나머지는 전부 잉크 — 본문 #242424, 보조 #6B6B6B. 페이지에는 box-shadow도 gradient도 0개이며, 구조는 1px 규칙선으로 그려진다. 그것도 옅은 회색이 아니라 신문이 단을 가르듯 거의 검은 #242424 헤어라인이다.

버튼만이 유일하게 부드럽다. 모두 99em 풀 캡슐 pill이고, 그 외 모든 모서리는 직각(0)이다. pill과 사각의 이중성이 이 사이트의 조용한 시그니처다. 기본 CTA는 한 컴포넌트에서 두 스킨으로 출고된다 — 그린 pill(#1A8917 → hover #156D12)과 거의 검은 pill(#191919 → #000000), 둘 다 196px.

모션은 거의 없다. 트랜지션은 background-color / color에 한정되고 300ms linear뿐 — transform도, 애니메이션 그림자도 없다. 페이지는 연기하지 않는다. 인쇄된 표지처럼 가만히 앉아 타이포그래피를 믿는다.

레이아웃 패턴

1192px 컨테이너 · flexbox 기반 · 2-zone hero split(좌측 텍스트 + 우측 floating 일러스트). 카드 chrome 없음.

Grid System

  • Content max-width: 1192px (nav / page container .bh)
  • Grid type: Flexbox (atomic .g{display:flex}, hero에 CSS Grid 없음)
  • Columns: hero = 2 zones (text + absolute 일러스트)
  • Gutter: side margin 24 / 48 / 64px 반응형

Hero

  • Pattern: min-height 560px + 단색 cream + 좌측 GT Super H1 + pill CTA + 우측 absolute 일러스트
  • Background: 단색 #F7F4ED (gradient / noise / overlay 없음)
  • H1: 70–120px / weight 400 / ls -0.05→-0.055em / #000000
  • Max-width: 720px (텍스트 단)

Section Rhythm

  • Hero: cream 단색 + overflow hidden
  • Margin: 75px top / 64px side / 0 bottom
.hero {
  background: #F7F4ED;   /* cream */
  min-height: 560px;
  margin: 75px 64px 0;   /* top, side, bottom */

Card Patterns

  • 홈페이지 hero에 카드 컴포넌트 없음 — 우측은 일러스트 1개, 카드 그리드 아님

  • Border: border-bottom: solid 1px #242424 — 시그니처 near-black 규칙선
  • Container: max-width 1192px, logo 25px (fill: #242424)

Content Width

  • Prose / reading: 680–720px (Medium 리딩 measure)
  • Container: 1192px
  • Footer: 680px

Do / Don't

실제 CSS에서 검증된 규칙만 수록.

DO

  • 마케팅 표면은 따뜻한 크림 #F7F4ED, 앱/리딩 표면은 #FFFFFF로 분리할 것
  • GT Super(serif display) + Söhne(sans body)를 짝지을 것 — 역할 고정
  • 모든 버튼을 pill(border-radius: 99em)로 만들 것
  • nav/footer 구분은 1px solid #242424 하드 라인으로 그릴 것
  • 본문 텍스트 #242424, 보조 #6B6B6B, 헤드라인만 #000000
  • 브랜드 그린 #1A8917, hover #156D12 — accent/CTA/링크에만
  • display tracking -0.055em (큰 사이즈일수록 더 타이트하게)

DON'T

  • 마케팅 배경을 #FFFFFF 또는 white로 두지 말 것 — 대신 #F7F4ED
  • 본문 텍스트를 #000000/black으로 두지 말 것 — #242424 사용 (순흑은 hero 전용)
  • font-weight: 600 사용 금지 — Medium은 500 다음 700 (600 부재)
  • 버튼을 border-radius: 8px 같은 고정 px로 두지 말 것 — 99em
  • nav/footer 강조 라인을 #E5E5E5 옅은 회색으로 두지 말 것 — #242424 1px
  • box-shadow로 깊이 만들지 말 것 — 그림자 0개, 1px 보더만
  • linear-gradient/radial-gradient 금지 — 단색 fill만
  • 브랜드 그린을 본문/chrome 전반에 쓰지 말 것 — accent 전용
  • hover에 transform/scale/box-shadow 금지 — background-color 300ms linear만
What This Site Doesn't Use (Negative-Space Identity)
  • Box-shadow: zero — 1px 헤어라인이 모든 구조 작업을 한다
  • Gradients: none — 모든 표면에 단색 fill만
  • Weight 600: absent — 300 / 400 / 500 / 700만
  • Mid-range radius: none — 99em pill과 50% circle뿐, 표면은 0
  • Pure black on body text: never — #000000은 hero 헤드라인 한 곳뿐
  • Transform / scale hover: none — 인터랙션은 color-only, 300ms linear
  • Second brand color: none — #1A8917이 유일한 채도 브랜드 값
  • Card chrome on homepage: none — 일러스트 + 타입이 hero를 운반
  • Eased motion: none — 모든 transition은 linear
Known Gaps: 분석은 로그아웃 홈페이지(LOHP) 단일 페이지 기준. HTML/CSS는 Wayback Machine 스냅샷(20260625215241)에서, 렌더 스크린샷은 라이브 사이트에서 수집(약 1일 차). green vs black CTA는 한 컴포넌트에서 둘 다 출고되며 어느 브레이크포인트/A·B 버킷에서 무엇이 렌더되는지 미확정. 브레이크포인트(~728 / ~1080 / ~1304px)는 헤드라인 스케일 클래스에서 역산한 근사값. 다크 모드 / 폼 컴포넌트 / 리딩 타이포는 이 경로에서 미관측.
